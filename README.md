# alismanifesto.com

Ali Akbar's resume site: a static page served by GitHub Pages, no build step.

- `index.html`, `styles.css`, `script.js`: the page.
- `assets/pixel/`: pixel art, generated by `python3 tools/pixelart.py`. Edit a sprite grid there and rerun it.
- `assets/fonts/`: self-hosted Inter, Pixelify Sans and Silkscreen (SIL Open Font License 1.1), so the page loads nothing from third parties and can keep a strict CSP.
- `.well-known/security.txt`: where to report a vulnerability. Renew `Expires` yearly.
